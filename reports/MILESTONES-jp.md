## 1. マイルストーン全景

本プロジェクトはアジャイル開発手法を採用し、バイナリ解析からネイティブ GUI 実装に至るまで、5 つの明確な工程段階に分割して推進されました：

| マイルストーン | 開発担当領域 | 主な成果物および検証項目 | 検証状況 |
|---|---|---|---|
| **第1段階 (M1)** | 基礎データ復号と形式検証 | PAK 内 403 ファイル抽出完了、24×24 フォント出力、LFG 画像展開 | ✅ **受入完了** |
| **第2段階 (M2)** | SCN 逆アセンブルと VM 基盤 | 197 本のスクリプト逆アセンブル出力、外層 Block 遷移、13 種 Skip 命令 | ✅ **受入完了** |
| **第3段階 (M3)** | ネイティブ音響系と混音処理 | Ogg BGM 25 曲ループ再生、WAV 効果音 13 本混音、CoreAudio リサンプリング | ✅ **受入完了** |
| **第4段階 (M4)** | Metal 描画と高忠実度復元 | 25×13 サウンドノベル文字組、3 パス影文字、13 種トランジション、隠し音楽室 | ✅ **受入完了** |
| **第5段階 (M5)** | 最適化・プラットフォーム適合 | macOS App Nap 対策、多言語ビルド基盤、独立 DMG 配布イメージ (Ver.1.0) | ✅ **正式リリース** |

## 2. 詳細マイルストーン仕様および受入基準

### 第1段階：暗号解読とフォント組版パイプライン (M1)
- **M1.1: 独自 PAK コンテナの復号と整合性検証**
  - 11 バイト加算循環鍵アルゴリズムを実装し、`MAX_DATA.PAK` 内全 403 ファイルを抽出。
  - **受入基準**：403 ファイルすべてのハッシュ整合性を確認。ディレクトリ名に文字化けがないこと。
- **M1.2: KNJ 24×24 ビットマップフォントデコード**
  - `KNJ_ALL.KNJ`（133,344 バイト）内の 1,852 字を 3 垂直走査ストリップから復元。
  - **受入基準**：`preview/knj_atlas.png` を出力し、文字の欠損がなく、1-based 配列参照が正確であること。

### 第2段階：二層仮想マシンとスクリプト制御 (M2)
- **M2.1: SCN スクリプト伸張と境界切断処理**
  - 反転フラグ LZS3 伸張処理を実装し、ヘッダ記載の展開後サイズで厳密に切断。
  - **受入基準**：全 197 本のスクリプト末尾にゴミ文字の混入が一切生じないこと。
- **M2.2: イベント仮想マシン（Event VM）と Skip 命令処理**
  - 外層ストリームに存在する 13 個のダミー Skip オペコードを特定し、プログラムカウンタを安全に進める。
  - **受入基準**：`SCN001.DAT` から `SCN002.DAT` へのブロックジャンプがデッドロックなく滑らかに遷移すること。

### 第3段階：ネイティブ音響サブシステムの統合 (M3)
- **M3.1: LAC コンテナとオーディオグラフ構築**
  - `AVAudioEngine` による遅延ゼロの再生グラフを構築。25 曲の BGM ループ再生と 13 本の効果音混音を実現。
  - **受入基準**：BGM 移行時やフェードアウト時にポップノイズや音割れが発生しないこと。
- **M3.2: 11,025Hz モノラル音源による CoreAudio 例外クラッシュの根治**
  - `AVAudioConverter` を統合し、モノラル 11,025Hz 音声を 44,100Hz ステレオ Float32 へ動的リサンプリング。
  - **受入基準**：`P01-P13` 効果音の連続トリガー時にも `NSException` が一切発生しないこと。

### 第4段階：描画パイプラインと忠実度復元 (M4)
- **M4.1: サウンドノベル行組版と影文字描画**
  - 25 列 × 13 行の等幅グリッド、字間 1px、行間 6px、および 3 パス硬影文字重ね描きを再現。
  - **受入基準**：テキストボックスの半透明合成が Windows 95 原版とピクセル単位で一致すること。
- **M4.2: 13 種トランジションと螺回転換（GURUGURU）幾何アルゴリズム**
  - `(27, 12)` を中心とする 16px タイルブロックの外向き螺旋描画アルゴリズムを復元。
  - **受入基準**：40×25 タイルが欠落なく外向きに画面全体へ螺旋展開すること。
- **M4.3: 隠し音楽室の逆アセンブル解明と復元**
  - タイトル画面 `(448, 128)` の時計塔右上窓に対する不可視判定および `0x408d40` メインループを再現。
  - **受入基準**：`VIS17.LFG` 画面上でオルゴール調の音楽室 UI が起動し、ESC/マウス右クリックで正常に復帰できること。

### 第5段階：システム最適化および製品リリース (M5)
- **M5.1: macOS App Nap によるクロックダウン抑止**
  - `ProcessInfo.beginActivity([.userInitiated, .latencyCritical])` を適用。
  - **受入基準**：長文待機中および画面演出中を通じて、フレームレートが 60.0 FPS を維持すること。
- **M5.2: 独立配布イメージのパッケージング**
  - 外部ランタイム不要のスタンドアロン `.app` および DMG インストーラを生成。
  - **受入基準**：クリーンな Apple Silicon macOS 環境で直接起動・動作すること。
