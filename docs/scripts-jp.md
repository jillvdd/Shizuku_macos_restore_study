# SCN シナリオスクリプト仕様書（SCN%03d.DAT）

> 🌐 **Language / 多言語**: [🇨🇳 简体中文](scripts.md) ｜ [🇺🇸 English](scripts-en.md) ｜ [🇯🇵 日本語](scripts-jp.md)

参考実装：akkera102 `decscn.py` / `script.c`、GBALVNS `EVTDef.s`、XLVNS `LvnsScript.c`。
全 197 本のシナリオスクリプト（`SCN000.DAT` 〜 `SCN196.DAT`）にて検証済み。

## ファイル構造レイアウト

```text
0..1   u16 LE イベント部ファイルオフセット = 値 * 0x10
2..3   u16 LE メッセージ部ファイルオフセット = 値 * 0x10
[イベント部先頭までパディング]
イベント部：  u32 LE 展開後サイズ d1Size + lzs3 圧縮データ
メッセージ部：u32 LE 展開後サイズ d2Size + lzs3 圧縮データ
```

## イベント部（展開後）

```text
0..1   u16 LE 最終ブロック番号 last
2..    各ブロックのオフセット配列（u16 LE、Block 0..last）
以降   イベントバイトコードストリーム
```

ブロックはシナリオの遷移単位であり、エンジンは `(scnNo, blkNo)` に基づいてディスパッチします。ジャンプ命令 `0x04` は直接 `SCN%03d.DAT Block %d` を指定します。

### 主要イベントオペコード

| Opcode | 長さ | 意味論 |
|---|---|---|
| 0x00 | 1 | ブロック終了（BGM 停止、実行終了） |
| 0x01 | 3 | サブコマンド：01/02/04 テキスト表示、03 アニメーション待機 |
| 0x04 | 3 | ジャンプ：`SCN%03d.DAT block %02x` |
| 0x05 | 3+2N | 選択肢分岐：メッセージ、選択肢数、(msg, jump) ペア |
| 0x07 | 1 | 直前選択のアンカーマーク |
| 0x0a | 2 | 背景指定 `MAX_S%02d` |
| 0x14 | 2 | 画面クリア |
| 0x16 | 2 | イベント CG ロード `HVS%02d` |
| 0x22 | 3 | 立ち絵配置 `MAX_C%02x`（左/中/右スロット） |
| 0x24 | 3 | クローズアップ立ち絵（中央強制） |
| 0x38 | 2 | 画面更新・フェードトランジション |
| 0x3d | 4 | 条件分岐 `if flag[c1] == c2` |
| 0x3e | 4 | 条件分岐 `if flag[c1] != c2` |
| 0x47 | 3 | フラグ代入 `flag[c1] = c2` |
| 0x48 | 3 | フラグ加算 `flag[c1] += c2` |
| 0x54 | 2 | メッセージ呼び出し |
| 0x6e | 2 | BGM ループ再生 |
| 0x7d | 2 | スタッフロール実行 |
| 0x7e | 2 | エンディング番号判定 |
| 0xff | 1 | 終端記号 |

## メッセージ部（展開後）

テキストは **葉文字コード（Leaf フォントコード）** で格納（`KNJ_ALL.KNJ` の 1-based インデックス）。最上位ビットがセットされたバイト（`c[0] & 0x80`）が 2 バイト文字コードを構成します。

制御トークン（ASCII < 0x80）：
- `$`: メッセージ終了
- `p`: 改ページ待機（クリックで画面消去）
- `k` / `K`: 入力待機（クリックで次行へ追記）
- `r`: 改行
- `B` / `E`: 背景変更
- `C`: 立ち絵変更
- `D`: 立ち絵消去
- `S`: 背景と立ち絵の一括転換
- `A` / `a`: 3人立ち絵配置
- `V`: ビジュアル CG
- `H`: Hシーン CG
- `M`: BGM フェード／次曲／停止
- `P`: PCM 効果音再生
- `Q`: パレット暗転
- `F`: 画面白フラッシュ
- `X`: 水平インデントオフセット
- `s`: 表示速度
