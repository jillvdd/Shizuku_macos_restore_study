## 事件段低使用率/未确认 opcode

| opcode | script.c 中的处理 | 证据强度 | 备注 |
|---|---|---|---|
| 0x02 | (未见专门 case) | 弱 | 未见 |
| 0x03 | 未知(2 字节) | 中 | 事件流中确实出现 |
| 0x06 | 未知(1 字节) | 中 | 同上 |
| 0x08 | 未知 | 弱 | 出现在 SCN 尾部(可能属选择表区域) |
| 0x09 | 未知 | 弱 | 同上 |
| 0x0b | 未知 | 弱 | 同上 |
| 0x5a | 未知(1 字节) | 中 | SCN001 出现(在 BGM/BG 之后,疑似"等待/效果") |
| 0x5c | 未知(2 字节) | 中 | — |
| 0x60-0x66 | 未知(1 字节) | 中 | 出现于事件流 |
| 0x6f / 0x73 | 未知 | 弱 | — |
| 0x01 子命令 03 | 动画等待(`AnimeExecSizuku`) | 高 | 语义基本确定 |
| 0x38 | 画面更新(淡入淡出) | 高 | 语义确定,参数细微待验证 |

> 备注:很多"未知"字节实际位于"选择跳转表"等**非顺序执行区**,未必是 opcode。需结合真实游戏流程判定(Phase 3 反汇编器 + Wine 观测)。

## 文本段未知命令

- `0`(0x30):script.c 标"未知 1 字节"。出现频率低。
- `X`(显示偏移)、`s`(显示速度)参数语义待验证。
- `P`(PCM)子命令 `l`/`0-9`/`f`/`w`/`s` 精确参数格式待验证。

## 其他待确认

1. **OPTSET.DAT 存档格式** — 未取得;需 Wine 运行原版生成样本后逆向,或逆向 EXE。
2. **P16 头部语义**(`02 00 0c 00`)与采样率 — Phase 2 实测。
3. **LAC 容器条目名称字段**(Shift-JIS)对提取无影响,仅作标注。
4. **汉化 EXE 内部数据**:中文字体/界面的具体组织(可选研究项)。
5. **块(block)偏移表精确语义**与 `0x05` 选择在真实数据中的跳转计算 — 用反汇编器对全部 197 个 SCN 统计后再确认。
